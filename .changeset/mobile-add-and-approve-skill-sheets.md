Add a skill to a space from Settings › Skills. The screen's "Add a skill" button now opens a sheet that lists the skills the providers on this computer already have, with the space each one is added to, and adds the one you pick. A skill that comes from a community folder opens a second sheet first: where it came from, the commit approving pins, what the bot will be told, and every file it brings. A .zip still has to be uploaded from the desktop app, and the sheet says so.
