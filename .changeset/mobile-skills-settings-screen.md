Mobile Settings now has a Skills screen. It lists every skill a bot in the space can load on demand, grouped by where the skill comes from — Community, This space, Built in, Provider — with the size it loads at, a "Yours" badge on skills added to all spaces, and a "Needs approval" badge on rows waiting for the user. The row and the screen stay hidden in a build with no skill registry, exactly as the web app does today. "Add a skill" is drawn but inert until the add flow lands.
