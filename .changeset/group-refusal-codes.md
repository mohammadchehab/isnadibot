Six ways a space command can be refused now name their reason, so clients show their own wording instead of the server's internal sentence. A space created without a boss, a boss asked to replace and unassign itself, and a leave that names someone other than the caller used to fall through to the raw invariant text; each now carries a refusal code with its own translated sentence. Creating a space from a template this build does not ship says so and points at updating the app, rather than echoing a template id that no refresh can produce.
