The skill registry screens, on dev fixtures. A space's Skills tab and Settings › Skills draw the registry the design calls for: one row per skill with its source, size and last load, the **This space / All skills / Unused** filters, and the three states a row can be in — needs approval, changed since approved, and needs a connector. This is phase 0. It reads a dev fixture, its actions are inert, and a shipped build hides the screen until a real source lands, so this ships as a patch rather than a feature.
