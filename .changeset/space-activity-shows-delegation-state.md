In a space's Activity, work one bot handed to another now gets its own row: the child bot, the task it was given, the state it is in, and an Open button that goes straight to its chat. Before, only the child chat appeared and the row said nothing about what happened to the delegation, so a queued or blocked hand-off looked the same as a finished one. The child chat no longer gets a second row of its own, since the delegation row is the same work with the state attached.
